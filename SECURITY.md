# Security Reporting Scope

## Scope

This repository contains public documentation and evidence identifiers only. It does not contain the ITHERLA runtime, source code, credentials, model files, private user data, or distributable software.

## Reporting accidental disclosure

If this repository appears to expose a credential, private path, personal information, private artifact, or security-sensitive implementation detail, report it through GitHub private vulnerability reporting if that feature is available. Do not place secrets, personal data, or reproducible exploit details in a public issue.

If private reporting is unavailable, open a minimal public issue that identifies the affected file without repeating the sensitive content.

## No public security program yet

ITHERLA has not announced a public bug-bounty program, safe-harbor program, production service, or supported public attack surface. This file does not authorize access to systems, accounts, devices, private repositories, or third-party services.
