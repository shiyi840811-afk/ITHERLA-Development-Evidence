# Contribution Policy

ITHERLA is not accepting public product contributions at this stage.

Please do not submit source code, architecture, prompts, datasets, model artifacts, executable packages, or unsolicited patches. This evidence ledger is intentionally separated from the private product repository.

Documentation corrections may be reported through a GitHub issue if issues are enabled. A report should identify the affected public file and the factual correction without including confidential material, credentials, private user data, or exploit details.

Unsolicited material does not transfer ownership, create an obligation to review, or grant permission for incorporation into ITHERLA. Any future contribution program will publish explicit terms before accepting contributions.

Security-sensitive reports should follow [SECURITY.md](SECURITY.md) instead of being posted publicly.
